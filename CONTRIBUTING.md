# Contributing

This repository holds the website for the ISC2 Arkansas chapter. One maintainer edits it, and it doesn't accept pull requests.

Found a broken link, a typo, or an accessibility problem? Open an [issue](https://github.com/tsudo/isc2arkansas.org/issues).

For questions about the chapter itself (meetings, membership, officers), email [info@isc2arkansas.org](mailto:info@isc2arkansas.org) rather than opening an issue.

You're welcome to reuse the code for your own chapter site under the license terms in [LICENSE](LICENSE). The photos, the ISC2 documents, and the ISC2 name and seal are not covered by that license; see the README.
