Privacy

This site has no forms, accounts, or cookies, and it does not track you across other sites.

We use Cloudflare Web Analytics to count page views. It does not set cookies or store personal data; we see totals, such as how many people visited and which pages they read.

If you email the chapter, your message goes to the chapter's Google Workspace mailbox and is read only by chapter officers. Ask at info@isc2arkansas.org if you want a message deleted.

If you appear in a photo on this site and want it removed, email the same address.
